# 대구 서바이벌 (Daegu Survival)

뱀파이어 서바이버즈식 아레나 서바이벌 게임 — 대구 여행 테마 리스킨.
원작 `duck-survival`(후더덕 서바이벌)의 대구 버전입니다.

- 🦆 막창 바주카포를 든 오리 vs 좀비 오리·비둘기 무리
- 🗺️ 대구 랜드마크 11곳: 대구역 · 동성로 · 팔공산 갓바위 · 서문시장 · 달성토성 · 근대골목 · 계명대 · 83타워 · 이월드 · 대프리카 · 수성못
- 🔫 대구 무기 6종: 대구 막창포 · 납작만두 스트라이크 · KTX 스파크 · 궤도 약령환 · 수성못 빙수 · 갓바위 레이저
- 🚄 KTX 탑승 (대구→동대구), 🏯 달성토성 방어전, 🏃 수성못 강제 2바퀴 조깅
- ⏱️ 서바이벌 / 타임어택(2분) 모드, 🐱 거대 고양이·보스 고양이·지브리풍 엔딩
- 한/일 2개국어, 모바일 조이스틱, 로컬 최고기록·랭킹
